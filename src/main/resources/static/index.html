MicroSpringBoot

Un framework mínimo de IoC que utiliza Java Reflection

Endpoints disponibles:

/
Returns a greeting message
/hello
Returns "Greetings from Spring Boot!"
/pi
Returns the value of PI
/greeting
Returns "Hola World" (default)
/greeting?name=Maria
Returns "Hola Maria" (with @RequestParam)

Built with Java 21 | Reflection API | Custom Annotations
